# Dossier de préparation · EPSO/AD/427/26

App d'entraînement pour le concours européen EPSO/AD/427/26 (Graduate Administrators, grade AD5). Fichier HTML unique, JavaScript vanilla, aucune dépendance, aucun build.

## Modules

- **Verbal** · 62 textes au format réel du concours : un passage, quatre affirmations A/B/C/D, une seule pleinement démontrée par le texte. Chronomètre global de session.
- **Numérique + abstrait** · 16 questions numériques écrites et 20 générateurs qui tirent des chiffres neufs à chaque session ; séries abstraites produites par neuf familles de règles paramétrées sur un rendu SVG procédural, soit des milliers de séries distinctes. Les deux tests sont chronométrés séparément, comme au concours.
- **Connaissances UE** · cours en 9 sections et 222 questions.
- **Compétences numériques** · cadre DigComp et 111 questions.
- **EUFTE** · entraînement à l'essai libre sur 20 sujets européens, en mode libre ou en mode dossier avec sources, chronométré.
- **Annexe** · 21 sections de référence et 169 fiches thématiques condensées.
- **Stratégie** · plan de préparation et règles générales.

Dans les trois moteurs de session, l'ordre des options est permuté à l'affichage : la bonne réponse ne reste jamais à la même place d'une session à l'autre.

## Utilisation

Ouvrir `epso_ad5_prep.html` dans un navigateur. La progression est enregistrée localement par le navigateur, sans compte ni serveur.

Si le dépôt est publié via GitHub Pages, l'app est directement accessible à l'URL de la Page.
