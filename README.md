# Dossier de préparation · EPSO/AD/427/26

App d'entraînement pour le concours européen EPSO/AD/427/26 (Graduate Administrators, grade AD5). Fichier HTML unique, JavaScript vanilla, aucune dépendance, aucun build.

## Modules

- **Verbal** — textes courts, affirmations Vrai / Faux / Ne peut pas dire, chronométré
- **Numérique + Abstrait** — questions numériques (dont une partie générée avec des chiffres aléatoires à chaque session) et séries de formes abstraites (SVG procédural)
- **Connaissances UE** — cours en 9 sections + quiz
- **Compétences numériques** — cadre DigComp + quiz
- **EUFTE** — entraînement à l'essai libre sur des sujets européens (mode libre ou mode dossier avec sources), chronométré
- **Annexe** — fiches de référence complémentaires (piliers institutionnels, 17 grands dossiers du Parlement européen, ~170 fiches thématiques condensées)
- **Stratégie** — plan de préparation et règles générales

## Utilisation

Ouvrir `epso_ad5_prep.html` dans un navigateur. La progression est sauvegardée localement dans le navigateur (aucun compte, aucun serveur).

Si le dépôt est publié via GitHub Pages, l'app est directement accessible à l'URL de la Page.
